## Personal Level Index

- **Scope**: 개인 공통/일상 관리용 지침 묶음
- **Inheritance**: Charter Root Rule 세트 → Personal Stage 기본 규칙
- **Structure**
  - `01. Rules/` — Personal Custom Instructions, Prompt, 계약 규칙
  - `02. Guides/` — 템플릿, 체크리스트, 작업 절차 (필요 시 추가)
  - `99. Artifact/` — Master Prompt + 📌 지침 + Applied
- **Usage**
  1. 목적에 맞는 Rule을 `01. Rules`에서 선택
  2. 출력/검증 규칙이 필요하면 `02. Guides` 사용
  3. ChatGPT 등록 시 `99. Artifact/Applied` 또는 `📌` 지침을 붙여넣음
