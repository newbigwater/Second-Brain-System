# 📘 Grammar 전용 Execution Gate

## (출력 전 자동 검증 규칙 · 경량 Contract)

본 문서는 **Grammar 모드 출력물**이 사용자에게 전달되기 전에  
**반드시 통과해야 하는 최소 자동 검증 규칙(Execution Gate)** 이다.

본 Gate는 **Grammar Template의 실제 구조와 완전히 일치**하도록 재작성되었으며,  
Template을 충실히 따르는 정상 출력은 **의도치 않게 Fail 되지 않도록 설계**되었다.

---

## 0️⃣ Gate 성격 정의

- Grammar는 **설명형 학습 정리 산출물**이다
- Grammar는 **자유 출력이 아니다**
- 본 Gate는 **Template 준수 여부만을 검증**한다
- 모든 규칙은 **Guide ❌ / Contract ⭕**

👉 하나라도 위반 시 **출력 중단(Fail)**

---

## 1️⃣ Pre-Gate : 모드·요청 검증

### G-G01. 모드 확인
- [ ] Mode = `Grammar` 명시됨
- [ ] Podo 규칙 혼입 없음
- [ ] Podo 전용 Weekly Study 구조 미사용

❌ 실패 시: **Fail**

---

### G-G02. 요청 해석 검증
- [ ] “정리 요청”을 **요약**으로 처리하지 않았는가
- [ ] 설명 삭제·축약이 아닌 **구조 유지 재배치**로 처리했는가

❌ 실패 시: **Fail**

---

## 2️⃣ Structure Gate (Template 구조 기준)

### G-G10. Grammar 기본 섹션 존재

출력물에 아래 **Template 기준 섹션이 모두 존재**해야 한다.

- [ ] [Concept]
- [ ] [Why]
- [ ] [Form]
- [ ] [Examples]

❌ 하나라도 누락 시: **Fail**

---

### G-G11. 섹션 역할 오염 금지

- [ ] Concept에 규칙 나열만 존재하지 않는가
- [ ] Why가 단순 번역·중복 설명이 아닌가
- [ ] Form이 예문 설명으로 대체되지 않았는가

❌ 역할 혼선 발견 시: **Fail**

---

## 3️⃣ Example Gate (예문 검증 · Template 기준)

### G-G20. 예문 개수 충족
- [ ] 예문이 **1개 이상 5개 이하**인가

❌ 초과 또는 0개일 경우: **Fail**

---

### G-G21. 예문 출처 검증
- [ ] 예문은 **교재 또는 사용자 입력 기반**인가
- [ ] AI가 새 예문을 **임의 생성하지 않았는가**

❌ AI 임의 생성 판단 시: **Fail**

---

### G-G22. 난이도 제한
- [ ] 현재형 위주 구성
- [ ] 비기너 난이도 유지
- [ ] 장문·복문 과다 사용 없음

❌ 실패 시: **Fail**

---

## 4️⃣ Scope Gate (학습 범위 제한)

### G-G30. 학습 범위 일치
- [ ] **금주 실제 학습 문법만 포함**
- [ ] 관련 없는 문법 개념 확장 없음

❌ 실패 시: **Fail**

---

### G-G31. 회화 침범 금지
- [ ] Conversation 형식 사용 ❌
- [ ] 말하기 연습 유도 문장 ❌
- [ ] 질문형 연습 Prompt ❌

❌ 발견 시: **Fail**

---

## 5️⃣ Output Format Gate

### G-G40. 출력 형식 검증
- [ ] 단일 Markdown 코드 블록
- [ ] 코드 블록 외 텍스트 출력 없음

❌ 실패 시: **Fail**

---

## 6️⃣ Final Gate (출력 허가 조건)

아래 조건을 **모두 만족할 때만 출력 허가**

- [ ] Pre-Gate 전부 통과
- [ ] Template 구조 완전 일치
- [ ] 예문 개수·출처·난이도 적합
- [ ] 학습 범위 오염 없음
- [ ] 출력 형식 위반 없음

➡️ **ALL PASS → OUTPUT OK**  
➡️ **ANY FAIL → OUTPUT BLOCK**

---

## 7️⃣ Gate 선언 (고정)

> Grammar 출력은  
> “설명을 많이 한 문서”가 아니라  
> **Template과 규칙을 정확히 지킨 학습 정리**만 허용한다.

본 Execution Gate는  
**Grammar Template을 보호하기 위한 최종 안전장치**로 작동한다.
