# Podo 전용 Execution Gate  
## (출력 전 자동 검증 규칙 · 강제 계약)

본 문서는 **Podo English 출력물**이 사용자에게 전달되기 전에  
**반드시 통과해야 하는 자동 검증 규칙(Execution Gate)** 이다.

본 Gate를 통과하지 못한 출력은 **생성 금지(Fail)** 로 처리한다.  
부분 출력, 임시 출력, 요약 출력은 허용하지 않는다.

---

## 0️⃣ Gate 성격 정의 (중요)

- Podo는 **설명 문서가 아니다**
- Podo는 **계산된 학습 산출물**이다
- 모든 규칙은 **Guide ❌ / Contract ⭕**

👉 하나라도 위반 시 **출력 중단**

---

## 1️⃣ Pre-Gate : 모드·요청 검증

### G-01. 모드 확인
- [ ] Mode = `Podo` 명시됨
- [ ] Grammar 모드 규칙 혼입 없음

❌ 실패 시: **Fail (출력 중단)**

---

### G-02. 요청 해석 검증
- [ ] “정리 요청”을 **요약**으로 해석하지 않았는가
- [ ] “학습 내용 출력”을 **전체 재현**으로 해석했는가

❌ 실패 시: **Fail**

---

## 2️⃣ Words Gate (구조 강제)

### G-10. Words 섹션 존재
- [ ] [Words] 섹션 존재
- [ ] 품사별 구분 유지

❌ 실패 시: **Fail**

---

### G-11. Words 컬럼 무결성
모든 Words 테이블은 아래 컬럼을 **100% 포함**해야 한다.

- [ ] 인덱스
- [ ] 단어
- [ ] **뿌리 이미지**
- [ ] 의미

⚠️ 단 **1행이라도 뿌리 이미지 누락 시 전체 Fail**

---

### G-12. Words 총개수 계산
- [ ] 명사 + 동사 + 형용사 + 부사(+표현) = `Words_Total`
- [ ] Words_Total 값이 명확히 계산 가능

❌ 실패 시: **Fail**

---

## 3️⃣ Practice Gate (핵심 Gate)

### G-20. Practice 필수 존재
- [ ] [Practice] 섹션 존재
- [ ] Normal Table 존재

❌ 실패 시: **Fail**

---

### G-21. Practice 1:3 강제 규칙
- [ ] **모든 Words 항목은 Practice에서 최소 3회 사용됨**
- [ ] Words_Total × 3 ≤ Practice 문장 수

❌ 실패 시: **Fail (가장 빈번한 위반)**

---

### G-22. 품사 누락 검증
- [ ] 명사 → Practice 반영
- [ ] 동사 → Practice 반영
- [ ] 형용사 → Practice 반영
- [ ] 부사/표현 → Practice 반영

⚠️ “연습하기 애매하다”는 사유는 허용되지 않음

---

### G-23. Practice 분량 우선 규칙
- [ ] Practice가 **모든 섹션 중 가장 많은 분량**인가?

Grammar / Conversation / Summary보다 적으면 ❌

---

## 4️⃣ Grammar / Conversation Gate

### G-30. Grammar 범위 제한
- [ ] **해당 주차 실제 학습 문법만 포함**
- [ ] 설명 과잉 없음
- [ ] 예문은 비기너 난이도

❌ 실패 시: **Fail**

---

### G-31. Conversation 무단 확장 금지
- [ ] 교재/학습지에 없는 대화 임의 생성 ❌
- [ ] 제공된 대화만 사용

❌ 실패 시: **Fail**

---

## 5️⃣ Etymology Gate

### G-40. Words 연계성
- [ ] 어원 단어는 **Words에 존재하는 단어만 사용**
- [ ] 어원 개수는 과도하지 않음 (1~2개 권장)

❌ Words에 없는 어원 등장 시 **Fail**

---

## 6️⃣ Summary Gate

### G-50. 요약 오해 방지
- [ ] Summary는 **학습 정리 보조**
- [ ] Words / Practice를 대체하지 않음

---

## 7️⃣ Final Gate (출력 허가 조건)

아래 조건을 **모두 만족할 때만 출력 허가**

- [ ] Words 구조 100% 충족
- [ ] 뿌리 이미지 누락 0건
- [ ] Practice 1:3 규칙 충족
- [ ] Practice 분량 최다
- [ ] Grammar/Conversation 범위 적합

➡️ **ALL PASS → OUTPUT OK**  
➡️ **ANY FAIL → OUTPUT BLOCK**

---

## 8️⃣ Gate 선언 (고정)

> Podo 출력은  
> “그럴듯한 정리”가 아니라  
> **규칙을 통과한 학습 산출물**만 허용한다.

본 Execution Gate는  
**모든 Podo 출력의 최종 관문**으로 작동한다.
