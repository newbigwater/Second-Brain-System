## 1. 목적

본 문서는 SCS 단계에서 사용되는 **AI 관련 모든 규칙 문서의 단일 진입점(Index)** 이다.

---

## 2. SCS AI Rule 전체 구조

```
⚙️ Forge – SCS Root Rule (v1.1)
└─ 📘 AI Coding Behavior Rule
   └─ 🟦 SCS Task Execution Playbook
```

---

## 3. Rule 문서

- ⚙️ Forge – SCS Root Rule  
- 📘 AI Coding Behavior Rule  
- 🟦 SCS Task Execution Playbook  

---

## 4. Guide 문서

Guide 문서는 **사내 구성원을 위한 참고 가이드**이며,  
AI 내부 규칙이 아니다.

- 🧭 **SCS Prompt Authoring Guide**  
  → AI에게 요청을 잘 작성하기 위한 사용자 가이드
- 👤 **Personal Instruction**  
  → SCS 전용 AI 초기 행동 조건 및 요약 지침

---

## 5. 공식 산출물

Forge 단계에서 생성되는 공식 산출물은 다음과 같다.

- 📄 **Software Construction Specification (SCS)**  
  → 구현 명세서

- 💻 **Source Code (Complete, Buildable)**  
  → 완전하고 빌드 가능한 소스 코드

- 🧪 **Unit / Integration / System Test Report**  
  → 단위/통합/시스템 테스트 결과 보고서

- 🔄 **CI/CD Pipeline Configuration**  
  → 지속적 통합/배포 파이프라인 설정

- 🚀 **Deployment / Release Manual**  
  → 배포 및 릴리스 매뉴얼

---

## 6. 사용 원칙 요약

- AI는 Rule 문서만 따른다
- 사람은 Guide 문서를 참고한다
- 충돌 시 Root Rule이 최우선이다

### 6.1 규칙 우선순위

SCS 단계에서 규칙 적용 우선순위는 다음과 같다.

1. **⚙️ Forge – SCS Root Rule** (최상위)
2. **📘 AI Coding Behavior Rule** (하위 행동 규칙)
3. **🟦 SCS Task Execution Playbook** (실행 절차 규칙)

> 하위 규칙은 상위 규칙을 보완할 수 있으나, 충돌 시 상위 규칙이 우선한다.
