## 📌 요약 정리
|구분|핵심 질문|사용 위치|
|---|---|---|
|**PARA**|이 정보를 **어디에 둘까?**|폴더 구조|
|**CODE**|이 정보를 **어떻게 쓸까?**|작업 흐름|
|**CMDS**|이 정보를 **어떻게 발전시킬까?**|노트 내용 구성|

```mathematica
📁 OneDrive/ ← 강의자가 제공한 원자료 저장소 (읽기 전용, 저작권 주의)
└─ Resource/  # PARA: Resource / CODE: Capture / CMDS: Connect
   ├─ development/
   │   └─ Spring/
   │       ├─ FastCampus_Spring_Intro.pdf
   │       └─ 실습예제_01.zip
   ├─ language/
   │   └─ English_Basics.pdf
   └─ Improvements/
       └─ Building_SecondBrain.pdf

📁 iCloud/ ← 내 개념 정리, 실습 요약, 공유 초안 (다중 기기 접근)
└─ Area/    # PARA: Area / CODE: Distill / CMDS: Merge, Develop
   ├─ development/
   │   └─ Spring/
   │       └─ Spring_Intro.md
   ├─ language/
   │   └─ English/
   │       ├─ 단어_요약.md
   │       └─ 회화패턴_정리.md
   └─ Improvements/
       └─ SecondBrain/
           ├─ 제텔카스텐_개념정리.md
           └─ 메모_워크플로우.md

💽 ExternalDrive/ ← 실습코드, 실제 결과물 보관소 (GitX, PPT, 테스트 파일 등)
└─ Archives/       # PARA: Archive / CODE: Express / CMDS: Develop, Share
   ├─ development/
   │   └─ Spring/
   │       └─ Lab01_Signup/
   │           ├─ src/
   │           ├─ application.yml
   │           └─ README.md
   ├─ language/
   │   └─ English/
   │       └─ Script_Practice/
   │           ├─ 일일회화_1.md
   │           └─ 녹음파일.mp3
   └─ Improvements/
       └─ SecondBrain/
           └─ Workflows/
               ├─ Obsidian_템플릿.md
               └─ Publish_가이드.pdf
```
