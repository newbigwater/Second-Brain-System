## 📚 CMDS (Connect / Merge / Develop / Share)
> **“정보를 지식으로 발전시키는 흐름”**

### 단계 설명
| 단계              | 설명       | 예시                     |
| --------------- | -------- | ---------------------- |
| **C – Connect** | 흥미/질문 연결 | 이 강의 왜 보는지?, 뭘 배우고 싶은지 |
| **M – Merge**   | 내 언어로 요약 | 개념 재정리, 핵심 문장          |
| **D – Develop** | 실습/연구    | 테스트, 코드 실험, 리서치        |
| **S – Share**   | 외부로 표현   | 블로그, 발표, 사내 문서         |

📘 **학습/강의 정리에 최적화됨**
