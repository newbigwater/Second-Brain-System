## 🗃️ PARA (Projects / Areas / Resources / Archives)
> **“정보를 어디에 저장할 것인가?”**

### 구성 요소
| 항목                | 설명             | 예시                |
| ----------------- | -------------- | ----------------- |
| **P – Projects**  | 진행 중인 단기 과제    | 블로그 개편, 스프링 발표 준비 |
| **A – Areas**     | 지속적으로 관리하는 관심사 | Java, AI 공부, 체력관리 |
| **R – Resources** | 참고용 외부 자료      | 책 요약, 강의 노트, 링크   |
| **A – Archives**  | 완료된 정보 보관      | 끝난 프로젝트, 오래된 메모   |

📦 **폴더 정리 기준으로 최적화됨**

## 🔁 CODE (Capture / Organize / Distill / Express)
> **“정보를 어떻게 소화하고 표현할 것인가?”**

### 단계 흐름
| 단계               | 설명       | 예시                             |
| ---------------- | -------- | ------------------------------ |
| **C – Capture**  | 빠르게 수집   | 메모, 북마크, 스크랩                   |
| **O – Organize** | PARA에 분류 | `Resources > Lecture > Spring` |
| **D – Distill**  | 핵심 요약    | 내 언어로 요약/정리                    |
| **E – Express**  | 아웃풋 만들기  | 블로그, 문서, 발표자료                  |
